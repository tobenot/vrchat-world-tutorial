# 关于页海报

本目录下的图片会被 `src/components/Posters.astro` 自动扫描，并显示在 `/about/` 页面（位于「关于作者」区块下方）。

## 用法

把 1-4 张 **16:9** 的图片丢进这个目录就行，组件会自动按文件名字母顺序排列。

支持格式：`webp` / `png` / `jpg` / `jpeg` / `avif`。**强烈推荐 webp**（体积小、加载快）。

### 推荐命名

```
01-cover.webp
02-scene-night.webp
03-scene-day.webp
04-credits.webp
```

数字前缀只是为了控制顺序，名字本身不会显示给读者。

### 尺寸建议

- 宽高比：**16:9**（不是的话 CSS 会用 `object-fit: cover` 裁剪显示）。
- 推荐分辨率：`1920×1080` 或 `1440×810`，组件会自动生成 480 / 720 / 1080 / 1440 多档响应式版本。
- 单文件控制在 200 KB 以内最好。

### 可选：图注

如果想给某张图加文字说明，在 `Posters.astro` 调用处传 `captions` prop（key 是图片文件名去掉扩展名）：

```astro
<Posters captions={{ '01-cover': '世界封面', '02-scene-night': '夜晚场景' }} />
```

不传就不显示图注。

### 没图也没事

目录为空时，组件直接不渲染任何东西，about 页不会出现空白块。
