本章使用 Windows 上的 VRChat Creator Companion（VCC）图形界面创建世界项目。Unity 编辑器、SDK 和项目依赖需要兼容，VCC 可以协助安装官方指定版本并管理包。

## 工具的分工

```text
VRChat Creator Companion (VCC)
  ├─ 创建项目、管理 VRChat 包和依赖
  ├─ Unity Hub：安装与管理 Unity 编辑器
  └─ Unity Editor：编辑场景、资源与脚本
       └─ Worlds SDK：检查、构建和上传世界

VRChat 客户端：加载本地构建结果进行测试
代码编辑器：编辑 .cs 文件并显示语法诊断
```

VCC、Unity Hub 和 Unity Editor 是不同程序。SDK 则安装在 Unity 项目中。VRChat 账号的 SDK 登录入口在 Unity 的 VRChat SDK 控制面板，不是创建 VCC 本地项目的前置登录步骤。

## 第一步：安装 VCC

1. 打开 [VRChat 官方 SDK 页面](https://creators.vrchat.com/sdk/)，进入 Creator Companion 下载入口。
2. 运行官方安装包，完成安装并打开 VCC。
3. 按 VCC 的设置提示检查 Unity Hub 和 Unity Editor。

VCC 的图形界面以 Windows 工作流为主。其他操作系统的支持范围和命令行工具见 [VCC 入门文档](https://vcc.docs.vrchat.com/guides/getting-started/)。

## 第二步：安装支持的 Unity 版本

1. 打开 [Current Unity Version](https://creators.vrchat.com/sdk/upgrade/current-unity-version/)，核对官方指定的完整版本号。
2. 优先使用 VCC 提供的安装流程；已有 Unity Hub 时，也可以用官方页面的安装链接。
3. 在 Hub 中确认安装的是同一个完整版本，包括末尾的 `f1` 等修订标记。
4. 按 Unity Hub 的提示完成账号和许可证设置。

本章测试 Windows 世界，不需要同时安装所有平台模块。制作 Android 构建时需要为这个 Unity 版本安装 Android Build Support 及其依赖；可在 Hub 中对已安装版本使用 `Add Modules`。

:::caution[打开项目时核对版本]
Unity Hub 可能提示安装其他版本。这个提示不表示该版本受到 VRChat SDK 支持。用其他编辑器版本打开已有项目，可能触发资源重新导入或项目升级；升级前保存可恢复的项目备份，并遵循官方迁移说明。
:::

## 第三步：创建 World 项目

1. 在 VCC 中选择创建新项目。
2. 模板选择 **World**。
3. 名称填写 `MyFirstWorld`。
4. 选择本地目录，例如 `D:\VRChatProjects\MyFirstWorld`。
5. 创建项目，等待模板和依赖安装完成。

选择较短、便于辨认的路径，可以减少长路径对工具兼容性的影响。避免把正在编辑的工程放在会实时同步或产生冲突副本的目录中；如果桌面受 OneDrive 同步，也有同样的问题。中文路径本身不等于工程不可用，关键是实际使用的工具是否支持该路径，以及总长度、权限和同步状态。

## 第四步：打开并检查项目

在 VCC 项目列表中打开 `MyFirstWorld`。首次打开时，Unity 需要导入资源、解析包和编译脚本，所需时间取决于硬件、网络和项目内容。任务仍有进度或日志输出时，让导入完成。

检查以下内容：

1. 顶部菜单有 `VRChat SDK`。
2. Project 面板的 `Packages` 中能看到 Worlds SDK 相关包。
3. 打开 `Window → General → Console`，检查是否存在阻止编译或导入的错误。
4. 用 `Ctrl+S` 保存当前场景；如果没有场景路径，保存到 `Assets/Scenes/`。

警告与错误需要按具体内容处理。黄色警告不一定阻止构建，但也不能统一忽略。

## Unity 面板

- **Scene 视图**：编辑场景中的位置、形状和灯光。
- **Hierarchy**：当前打开场景的 GameObject 层级。
- **Inspector**：选中对象的组件、字段和资源属性。
- **Project**：项目资源与包的文件视图。
- **Console**：编译、导入与运行日志。
- **Game 视图**：显示场景摄像机的输出；编辑器模拟结果不等于完整 VRChat 客户端行为。

需要编辑 C# 时，在 `Edit → Preferences → External Tools` 选择已安装且支持 Unity 的代码编辑器。双击 `.cs` 文件，确认它可以打开。

## 保持可核查的初始环境

初始项目只保留 World 模板所需的官方包，便于确认工具链本身能构建。添加外部资源时，记录资源版本和新增依赖，每次导入后检查 Console 与构建结果。若导入前正常、导入后出现错误，这份记录可以缩小排查范围。

## 启动问题检查

- **VCC 找不到 Unity**：在 Hub 确认完整版本已经安装，再在 VCC Settings 中指定对应编辑器路径。
- **导入没有进展**：检查进度窗口、Console、编辑器日志、磁盘空间和包下载状态。没有统一的超时分钟数能判断所有导入任务是否失败。
- **脚本编译失败**：记录第一条相关错误及文件位置，核对编辑器版本和包依赖。错误也可能来自资源脚本，不能一律归因于版本号。
- **SDK 菜单缺失**：检查 World 模板和 Worlds SDK 安装状态，并先处理阻止脚本编译的错误。
- **客户端未启动**：确认本机装有 VRChat，并在 SDK 的 Settings 中检查 VRChat Client 路径。

向社区询问时，提供可复现步骤、Unity 与 SDK 版本、完整错误文本和相关设置截图。公开截图前去掉账号凭据等无关信息。
