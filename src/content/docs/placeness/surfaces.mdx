同一个几何表面可以通过颜色、反射和法线变化表现为木头、砖或金属。材质不必追求写实；使用哪些通道取决于画面目标、观看距离与性能预算。

## PBR 贴图通道

PBR（Physically Based Rendering，基于物理的渲染）用一组表面参数计算光照。贴图文件数量不固定，多个通道可以打包在同一文件中。

| 输入 | 作用 | 导入注意 |
| :--- | :--- | :--- |
| Albedo / Base Color | 基础色 | 通常按 sRGB 颜色纹理导入 |
| Metallic | 金属度 | 数值数据，通常不勾 sRGB |
| Smoothness / Roughness | 光滑度 / 粗糙度 | 两者方向相反，需匹配 Shader |
| Normal Map | 改变着色使用的表面方向 | Texture Type 设为 Normal map |
| Occlusion / AO | 局部环境光遮蔽 | 数值数据，不能替代全部实时阴影 |
| Height | 高度数据 | 是否产生视差或几何位移由 Shader 决定 |

颜色图与数值图的导入方式不同。若 sRGB 设置错误，采样值会变化，可能影响颜色、金属度或粗糙度；不能只把它归为「烘焙偏色」。

## 给地板添加木纹

1. 从 [Poly Haven](https://polyhaven.com/textures) 或 [ambientCG](https://ambientcg.com/) 获取允许使用的木地板贴图包，并保留来源和许可证信息。
2. 将文件放入 `Assets/Textures/WoodFloor/`。
3. 对法线文件设置 `Texture Type = Normal map`，点击 Apply。
4. 创建材质 `Mat_Floor_Wood`。本节 PC、Built-in 管线对照使用 `Standard`；移动版另按目标 Shader 支持的通道配置。
5. 将颜色图放入 Albedo，将法线图放入 Normal Map。
6. Metallic 设为 `0`、Smoothness 先设为 `0.4`，Normal Strength 从 `1` 开始比较。
7. 把 `Mat_Floor_Wood` 赋给测试地板，在 Mesh Renderer 的 Materials 槽中核对引用。保留原地板材质，便于还原；只创建材质而未赋值不会改变场景表面。

Normal Map 改变光照中的表面方向，不会使地板的轮廓、碰撞或几何高度改变。贴图包若同时提供 DirectX / OpenGL 法线版本，需核对其 Y 通道约定和 Shader 要求。

## Tiling 与 Offset

Tiling 控制贴图按 UV 重复的次数，不直接指定现实米数。假设地板 UV 在整个表面覆盖 `0–1`，地板为 `8 × 8` 米，Tiling 设 `8, 8` 时，每次重复约占 `1 × 1` 米。

如果模型 UV 本来已经重复，或者物体缩放改变，结果也会变化。用砖块、木板等已知尺寸的纹理细节核对比例。

Offset 改变采样起点。调整相邻表面的 Offset 可以对齐纹理，但不能保证消除模型 UV 或法线接缝。同一材质资产上的修改会影响全部引用它的 Renderer。

## Occlusion 与通道打包

AO 纹理提供缝隙和凹陷的遮蔽信息。使用 Standard Shader 时，将正确通道格式的纹理放入 Occlusion 槽，再调 Strength 比较效果。

资源包中的 ORM 通常指 R=Occlusion、G=Roughness、B=Metallic，但必须查看资源说明。Unity Standard Shader 不直接采用这组打包约定：

- Metallic 图的 R 通道存金属度
- Smoothness 通常来自 Metallic 图的 Alpha，或按材质选项来自 Albedo Alpha
- Occlusion 使用其输入纹理的 G 通道

因此需要重新打包、反转 Roughness 得到 Smoothness，或选择支持该格式的 Shader。换成 URP 不是导入 ORM 的通用办法；VRChat 世界项目不能为贴图格式随意更换渲染管线。

## Metallic 与 Smoothness 分别控制什么

| 表面示例 | Metallic 起点 | Smoothness 起点 |
| :--- | :--- | :--- |
| 哑光油漆 | `0` | `0.1` |
| 清漆木地板 | `0` | `0.7` |
| 玻璃表面 | `0` | `0.95` |
| 抛光金属 | `1` | `0.85` |
| 哑面金属 | `1` | `0.4` |

这些只是对照值，不是材料测量标准。Smoothness 高不等于金属；它改变反射的清晰程度。金属度还影响漫反射与反射颜色。

干净表面的金属度通常接近两端。混合像素、污渍、氧化和不同材料的过渡可能需要中间值，不能一概禁止。

## Detail Map

大面积表面在近距离需要更多细节时，可以叠加较高频的 Detail Albedo 或 Detail Normal。

Standard Shader 的 Secondary Maps 包含：

- `Detail Albedo x2`：细节颜色
- `Detail Normal Map`：细节法线
- `Detail Mask`：控制细节出现范围
- 独立 Tiling / Offset：控制细节重复频率

例如使用 `512 × 512` 的细节纹理，将 Tiling 设为 `10, 10` 与不使用细节纹理的版本比较。它增加纹理采样和资源开销，是否保留取决于实际可见收益。

## Shader 的选择条件

### Standard

适用于 Built-in Render Pipeline 的 PBR 材质，可配合 Lightmap、Light Probe 和 Reflection Probe。检查需要的渲染模式与平台性能，不把它作为所有材质的唯一选择。

### Unlit 与 Toon

Unlit 不按普通受光材质计算场景照明，适合需要固定显示颜色的界面或风格化表面。Toon 是一类风格化着色方法，不等于全部都由 Unlit 改成，也不代表完全不受光。

lilToon、Poiyomi 等社区 Shader 有各自的平台、功能与许可条件；采用前查发布者文档。Silent's Filamented 属于 PBR 方向，不能归到同一类 Toon 名单中。

### Mobile Shader

Android 世界允许自定义 Shader，但需验证兼容性与开销；头像 Shader 的白名单不能套到世界上。SDK 的移动端 Shader 可作为简化材质的候选，具体支持哪些法线、反射和透明功能，应按所选 Shader 核对。

PC 与 Android 可以共享兼容材质，也可以维护两套。需要视觉差异或不同性能配置时再拆分，不能写成任何项目都必须两套。

## 贴图导入设置

```text
Texture Type        Default / Normal map / Sprite
sRGB                颜色图通常开启；数值图按 Shader 要求关闭
Generate Mip Maps   3D 场景表面通常开启
Wrap Mode           Repeat（重复表面）/ Clamp（边缘不重复）
Filter Mode         Bilinear / Trilinear，按实际远景效果选择
Max Size            按观看距离和设备预算设置
Android Override    按平台设置尺寸与格式
```

Mip Maps 使用逐级缩小的纹理，有助于远处采样稳定。完整二维 mip 链的像素总量约增加三分之一，不应笼统说成只占「一点点」内存。

保持格式相同时，贴图边长翻倍约使像素数量变为四倍。Android 上 1K 是官方优化建议，并非所有纹理的硬上限。检查构建结果与运行时内存。

## 砖墙对照练习

1. 获取砖墙贴图并核对使用许可。
2. 在 PC、Built-in 管线中创建使用 Standard 的 `Mat_Wall_Brick`，配置 Albedo、Normal 和 Occlusion，并赋给一面测试墙的 Mesh Renderer。
3. 从 Metallic `0`、Smoothness `0.15`、Normal Strength `1` 开始。
4. 根据墙尺寸和 UV 调 Tiling，使砖块大小符合设计。
5. 若改变了参与间接光的材质，按第 36 章流程重新检查烘焙。
6. 在同一相机位置比较仅 Albedo、加入 Normal、加入 AO 的版本。

这三版使用同一块墙、同一 Albedo、同一光照与观察位置。先让 AO Strength 为 `0`、Normal Strength 为 `0` 记录基线，只把 Normal Strength 改为 `1` 记录第二版，再只把 AO Strength 改为 `1` 记录第三版。以正确格式导入并放入贴图槽，数值变化才有对应输入。AO 的可见程度还取决于环境光与 Shader，不保证任意直射光下都明显。

再做两个比较：把同一材质的 Tiling 依次设为 `1, 1`、`4, 4`、`12, 12`，记录同一块墙上砖块的实际大小；新建一个使用 Standard 材质的球，Metallic 固定为 `1`，在同一光照和已烘焙的 Reflection Probe 下把 Smoothness 依次设为 `0.2`、`0.6`、`0.95`。每次只改变一项参数，不复制到不同站位同时比较。需要独立调一面墙时复制材质，不直接改仍被其他墙共用的资源。

## 检查清单

- [ ] 颜色图、数值图和 Normal map 的导入方式正确
- [ ] 通道打包与所用 Shader 一致
- [ ] Tiling 对应实际表面尺度
- [ ] Normal、Height 与几何的作用没有混淆
- [ ] 重复使用的材质引用明确，未无意创建大量副本
- [ ] 平台构建中材质正常显示，资源开销经过检查
- [ ] 贴图与 Shader 的来源和许可已保留
