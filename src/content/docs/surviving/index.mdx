项目中的问题可能来自脚本、场景配置、平台差异、依赖或素材授权。调试定位原因，测试核对结果，版本管理保存修改，许可记录说明资源能如何使用。

按眼前的任务选择：

- 按钮没有响应、要查错误 → [调试与日志](./debugging-mindset/)
- 要验证上传前的行为与平台差异 → [分层测试](./testing-your-world/)
- 要协作、比较改动或恢复工程 → [版本管理和备份](./version-control/)
- 要引入素材或分享工程 → [许可与素材记录](./assets-and-licenses/)
