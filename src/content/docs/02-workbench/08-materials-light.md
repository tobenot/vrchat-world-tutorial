你的世界能跑了：地板、墙壁、一个发光球。但走进去看一眼——灰白色地板，雪白的墙，冷淡的默认天空。像毛坯房，干净但没有温度。

那些让你愿意留下来的 VRChat 世界——深夜雨中的暖光小屋、霓虹闪烁的未来街区——它们抓住你的第一步往往不是玩法，而是**进门那一秒的空间氛围**。

氛围从哪来？绝大部分取决于两样东西：**Material（材质）** 和 **Light（灯光）**。

这一章的目标很小：让你亲身体会同一个空间，改一下颜色和光的角度，传达的情绪就完全不同。

## 颜色是物体、光、角度三者的结果

你看到一个物体呈什么颜色，由三样东西共同决定：

1. 物体表面材质的底色（Albedo / Base Color）。
2. 打在它身上的光是什么颜色。
3. 光以什么角度和强度照过来。

同一面米白墙壁，暖黄灯下偏奶黄，冷蓝月光下偏灰蓝。墙没动，光一变，情绪就变。

所以搭建空间时，**调材质和调灯光必须同时进行**。

## 材质：物体的外衣

模型的形状由 Mesh（网格）决定，视觉外观由 Material（材质）决定。

同一个 Cube，穿上暗绿粗糙材质像铁盒，换成淡黄木纹像木料，换成半透明材质像玻璃。形状没变，观感完全不同。

::::tip[为什么是这样？]
形状和表面视觉为什么分开管？为了复用。一块古木材质可以同时穿在大门、书桌、地板上；同一个球体可以套金属材质、玻璃材质、石头材质。拆开管理，排列组合更自由。
::::

## 动手：给地板换件衣服

1. Project 面板 Assets 目录下新建文件夹 `Materials`。
2. 文件夹内右键 `Create` → `Material`，命名为 `Mat_Floor_WarmGray`。
3. 选中材质球，Inspector 里找到 **Albedo**（或 `Base Map` / `Base Color`），点色板选一个偏暖的灰色（想精确可以输入 `#8A8178`）。
4. 把材质球从 Project 面板**拖到** Scene 视图的 `Floor` 上。

地板立刻变成暖灰色。

## 材质面板的四个关键参数（先了解）

Albedo 下方还有几个控制质感的滑条：

* **Metallic**（金属感）：0 = 非金属（木头、棉布），1 = 纯金属（不锈钢、金）。
* **Smoothness**（光滑度）：0 = 粗糙（水泥），1 = 抛光镜面。
* **Normal Map**（法线贴图）：用一张 2D 贴图在平面上模拟凹凸细节（砖缝、划痕）。
* **Emission**（自发光）：让材质本身在暗处发光（霓虹、屏幕）。

这些参数基于 PBR（Physically Based Rendering，基于物理的渲染）。你不需要懂公式，拖动 Metallic 和 Smoothness 两个滑条就能配出塑料、金属或石头的感觉。

## 初学阶段：先用纯色

不要一上来就贴各种免费木纹贴图。纯色最容易控制整体基调：暖灰地板 + 米白墙壁 + 一个浅蓝发光球，三个颜色放在一起就已经有了雅致感。

**先用纯色定好冷暖氛围，等氛围对了再细化材质。** 大关系先于细节——这是三维美术的通用原则。

试着给墙壁也做个材质 `Mat_Wall_OffWhite`（Albedo `#D8D2C4`），给球做个 `Mat_GlowBall_Cyan`（`#6EE7F9`），分别拖上去看看效果。

## Directional Light：全局日光

场景默认的 `Directional Light` 相当于太阳。它有一个特点：**位置无所谓，只有 Rotation 角度起作用。**

* X 轴角度控制太阳高度：X = 90 是正午直射，X = 30 是低角度斜射（拉出长影子）。
* Y 轴角度控制水平朝向。

选中 Directional Light，把 Rotation 设为 `50, -30, 0`，Intensity 降到 `0.6`。

场景立刻有了午后的立体感——地板上出现了墙角投影，物体侧面有了明暗过渡。

::::tip[为什么是这样？]
阴影是大脑判断三维深度最重要的视觉线索。没有阴影的场景看起来像纸片。斜角光 = 长阴影 = 立体感。这也是为什么关卡设计师普遍偏爱斜射光。
::::

## Point Light：局部暖光

`Point Light`（点光源）像一颗灯泡，光从中心向四周散发，有距离衰减。

选中 `GlowBall` 上的 Point Light，试着调：

* **Color**：暖黄色让角落变温馨，冷蓝色让氛围变神秘。
* **Range**：3–6 之间适合营造局部光照角落，避免光穿透墙壁。

## 配光技巧：冷暖对比

如果你面对色板不知道怎么选，直接套这个经典组合：**冷调全局光 + 暖调局部光**（或者反过来）。

试试：把太阳（Directional Light）颜色设为淡蓝灰（`#9AB4C8`），强度 `0.3`；把球上的 Point Light 设为暖黄（`#FFE0B0`），强度 `2.5`。

Build & Test 进去看看。模型还是那几块 Cube，但冷灰蓝的全局背景加上角落里一抹暖光，已经有了「这里可以坐下来」的感觉。

这就是材质和灯光能做到的事：不写一行代码，只靠颜色和光，就能让空间传达情绪。

## 性能提醒

实时灯光的计算成本不低。场景里每多一盏实时 Point Light，显卡每帧都要重新算阴影。在 VRChat 的多人场景里，灯光数量需要节制。

目前学习阶段，两三盏灯完全没压力。后续进阶章节会讲怎么用灯光烘焙来省性能。

* GameObject：空壳。
* Component：能力模块。
* Prefab：可复用的模具。
* Material：视觉外衣。
* Light：空间情绪的开关。
