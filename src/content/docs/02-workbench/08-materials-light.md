# 8. 材质和光的第一印象

你的世界现在能跑了。有地板，有墙壁，有一个发光球。但进去看一眼，大概会觉得哪里不对。

灰色地板，白色墙壁，默认天空。像一个刚搭好框架的样板间，干净但毫无感觉。

那些你喜欢的 VRChat 世界——雨夜小屋、赛博朋克街道、安静的美术馆——它们之所以让你想待着，很大一部分原因不是交互多酷，而是**进去的那一刻，你就感受到了某种氛围**。

氛围从哪来？两样东西：材质和光。

这一章我们只碰这两件事。目标很小：让你体会到同一个空间，换一下颜色和光的角度，氛围就完全不同。

## 一个核心认知：颜色不是物体自带的

在 Unity 里（以及现实世界里），你看到一个物体是什么颜色，是三件事共同作用的结果：

1. **物体表面本身的颜色**（材质的 Albedo/Base Color）
2. **什么颜色的光照在上面**（光源颜色）
3. **光从什么角度照过来**（光源方向和强度）

同样一面白墙，在暖黄色的灯光下看起来像米色，在冷蓝色的月光下看起来像灰蓝色。墙没变，光变了，颜色就变了。

理解这一点之后，你就知道为什么"调材质"和"调灯光"必须一起做。只调材质不管光，或者只调光不管材质，都不会得到好的结果。

## 材质是表面的外衣

Unity 里，模型的形状由 Mesh 决定，但表面看起来是什么样子，靠 Material（材质）。

同一个 Cube，穿上深色材质就像金属盒子，穿上暖色材质就像木块，穿上半透明材质就像玻璃。形状没变，感觉完全两回事。

🤔 **为什么是这样？** 为什么形状和表面要分开管理？因为同一种表面（比如木头材质）可以穿在不同形状上（桌面、地板、门板），同一个形状（比如一个球）也可以穿不同的材质（金属球、玻璃球、石头球）。分开管理让你可以自由组合。

## 做一个材质：给地板换件衣服

在 Project 面板里新建一个 `Assets/Materials/` 目录。右键 → Create → Material。给它起个名字，比如 `Mat_Floor_WarmGray`。

选中这个材质，Inspector 里会出现一堆选项。先别管别的，只找颜色。在不同 Unity 版本和渲染管线里它可能叫 Albedo、Base Map 或 Base Color，都是同一个意思：**这个表面最基本的颜色。**

点开色板，选一个偏暖的灰色。如果你想要精确一点，试试 `#8A8178`（一种带温度的深灰）。

然后把这个材质从 Project 面板**拖到**场景里的 `Floor` 上。

地板立刻变色了。

就这么简单。你给一个物体换材质，就是把另一件衣服拖到它身上。

## 材质的其他属性（先只看不动）

打开材质的 Inspector，你会看到除了颜色之外还有很多属性：

- **Metallic** — 金属感。0 是非金属（木头、石头、布），1 是金属（钢、铝、金）
- **Smoothness** — 光滑度。0 是完全粗糙（砖墙、水泥），1 是完全光滑（镜面、抛光金属）
- **Normal Map** — 法线贴图。让平坦的表面看起来有凹凸细节（砖缝、木纹）
- **Emission** — 自发光。让材质本身发出光（霓虹灯、屏幕、发光标志）

现在不需要动这些。先只用颜色。但知道它们存在——以后你想让墙壁看起来像真正的石头而不是塑料，就是回来调这些值的时候。

🤔 **为什么是这样？** 这些属性来自一个叫 **PBR（Physically Based Rendering，基于物理的渲染）** 的概念。简单说就是：Unity 模拟了现实世界里光和材质互动的方式。金属会反射环境色，粗糙表面会散射光线，光滑表面会有高光。你不需要理解物理公式，只需要知道调这几个滑条就能让东西"看起来对"。

## 颜色先于一切细节

新手阶段先只用纯色。不贴纹理，不调粗糙度，不管金属感。

原因是：纯色最容易控制整体调性。你用暖灰色做地板，米白色做墙壁，浅蓝做发光球，三个颜色放在一起就已经有了「安静小屋」的雏形。一旦你开始贴纹理，细节太多，反而容易把空间搞得很乱。

**先用颜色定下整体氛围，等氛围对了，再加细节。** 这是所有美术方向的通用原则：大关系先于小细节。

给墙壁也做一个材质吧。叫 `Mat_Wall_OffWhite`，颜色设成 `#D8D2C4`（偏暖的米白）。给 `GlowBall` 也做一个，叫 `Mat_GlowBall_Cyan`，颜色设成 `#6EE7F9`（浅蓝绿）。

把材质拖上去。你的房间从「默认方块」变成了有一点设计的空间。

## 光决定你怎么看见这些颜色

材质给了表面颜色，但你能看见颜色，靠的是光。

同样一面米白色的墙，在冷白色的光下像办公室，在暖黄色的光下像咖啡馆，在低角度的橙光下像黄昏。材质没变，光变了，整个空间的感觉就变了。

这就是为什么很多 VRChat 世界创作者花在灯光上的时间比花在模型上的时间还多。灯光是"感觉"的开关。

## Directional Light：场景里的太阳

新场景通常自带一个 Directional Light。你可以把它想成太阳。

Directional Light 有一个特点：**它的位置不重要，方向很重要。** 不管它放在场景的哪个角落，光都是平行照过来的（就像太阳光——太阳离我们太远了，光线可以视为平行的）。决定光线方向的是它的 Rotation。

选中 Directional Light，试着改它的 Rotation：

- X 轴控制光的俯仰角。X = 90 是正上方照下来（正午），X = 30 是低角度斜射（黄昏感）
- Y 轴控制光从哪个水平方向来

试试 Rotation 设为 `50, -30, 0`。如果场景太亮，把 Intensity 从 1 降到 0.6 左右。

你会发现：只是改了光的角度和强度，同一个场景看起来就从「白天办公室」变成了「午后小屋」。地面出现了阴影，物体侧面有了明暗变化，空间一下子有了层次感。

🤔 **为什么是这样？** 光的角度决定了阴影的方向和长度。阴影给大脑提供了"这个物体有体积、有重量"的信息。没有阴影的场景看起来"平"，是因为大脑没有得到立体感的线索。这不是 Unity 的问题——现实世界里阴天光线均匀的时候，东西看起来也比晴天"平"。

## Point Light：局部的灯

Directional Light 是全局的，照亮整个场景。Point Light 是局部的，像一个灯泡，从一个点向四周发光。

你的 `GlowBall` 身上已经有 Point Light 了。它照亮附近的物体，营造局部氛围。

调 Point Light 的感觉很直觉：

- **Color** 决定氛围。浅蓝偏科幻，暖黄偏家居，浅紫偏神秘，橙红偏温暖
- **Intensity** 决定亮度。1 到 3 之间通常够用
- **Range** 决定能照多远。3 到 6 适合小型物件，8 到 15 可以照亮一个房间角落

🔀 **不同世界不同活法：** Chill 世界通常用多盏暗淡的 Point Light 营造柔和氛围。Game 世界用强烈的 Directional Light 确保玩家看清一切。Gallery 世界用 Spot Light（聚光灯）把光集中在作品上，其他地方保持暗。光的用法跟世界类型直接相关。

## 一个设计原则：冷暖对比

如果你不知道怎么配色和配光，试试这个简单原则：**让全局光偏冷，局部光偏暖**（或者反过来）。

比如：Directional Light 设成偏冷白（`#C5D5E4`），GlowBall 的 Point Light 设成暖黄（`#FFD4A0`）。冷暖对比让空间有张力，看起来不"死"。

这不是 Unity 特有的知识——这是所有视觉艺术通用的基础原则。电影摄影、舞台灯光、绘画配色，都在用冷暖对比。

## 关于性能的初步认知

这里提前说一件事，免得你以后踩坑：

**实时灯是"贵"的。** 你每多放一盏实时灯，Unity 就要多计算一遍光照。在 VRChat 世界里，性能很重要，因为多人同时在线时每个人的电脑都要渲染同一个场景。

第一阶段不用太紧张（两三盏灯完全没问题）。但养成意识：灯很好用，也不能随便堆几十盏。后面的章节（第 37 章）会专门讲怎么在好看和性能之间找平衡，包括烘焙光照这个关键技术。

## 动手：调出「雨夜小屋」第一版

现在试一件事。不加新模型，不加新脚本，只改材质和光，看看能不能让你的房间开始有一点点氛围：

1. 地板用暖灰色材质（`#8A8178`）
2. 墙壁用偏米色材质（`#D8D2C4`）
3. 把 Directional Light 的 Intensity 降到 `0.3`，Color 设成偏冷的蓝灰（`#9AB4C8`），Rotation 调成 `30, -45, 0`（低角度，模拟阴天）
4. 把 `GlowBall` 放到房间一个角落，Light 颜色设为暖色（`#FFE0B0`），Intensity 设为 `2.5`，Range 设为 `6`
5. Build & Test，进 VRChat 里走一圈

你会发现：模型几乎没变，地板还是那块 Cube，墙还是那面 Cube。但空间的感觉已经不同了。冷调的全局光让整体安静下来，角落里的暖色灯光像一盏台灯，给出了一个"可以靠近"的焦点。

这就是材质和光的力量。它们改变的不是几何形状，是**感受**。而感受决定了玩家愿不愿意在你的世界里多待一会儿。

## 自己改着玩

- 把 Directional Light 关掉（取消勾），只靠 Point Light 照明。整个房间变暗了，只有发光球附近有光。感受一下纯粹靠局部光源营造的氛围
- 把 GlowBall 的灯光颜色从暖色改成冷蓝（`#4FC3F7`），看看同一个空间的感觉怎么变化
- 再加一个 Point Light（创建空物体，加 Light 组件，Type 设为 Point），放在房间另一个角落，颜色设成浅紫（`#CE93D8`），看看两盏不同颜色的灯怎么互动
- 试试把 GlowBall 的材质的 Emission 打开，颜色设成跟 Light 一样的颜色。球体本身会"发光"，跟灯光配合起来更自然

## 回头看一眼

你现在知道了：

- 材质决定表面的外观，光决定你怎么看见这些表面
- 先用纯色定氛围，后加细节。大关系先于小细节
- Directional Light 像太阳（全局），Point Light 像灯泡（局部）
- 冷暖对比是最简单有效的配光方法
- 实时灯有性能成本，不要无限制地堆
