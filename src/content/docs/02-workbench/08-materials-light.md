你的世界能跑了：地板、墙壁、一个发光球。但走进去看一眼，灰白色地板，雪白的墙，冷淡的默认天空。像毛坯房，干净但没有温度。

那些让你愿意留下来的 VRChat 世界，暖光小屋、霓虹街区、窗外有月光的安静书房，它们抓住你的第一步，靠的往往是**进门那一秒的空间氛围**。玩法还在后面。

氛围从哪来？这章先抓两样东西：**Material（材质）** 和 **Light**。

目标很小：让你亲身体会同一个空间，改一下颜色和光的角度，传达的情绪就会变。

## 先做一个对照实验

打开你前面做好的房间。我们先不讲概念，先做一个小实验。

选中场景里的 `Directional Light`，在 Inspector 里把 **Intensity** 从默认值改到 `0.2`。房间会暗下来。再把它改到 `1.5`，房间会变得刺眼。接着把 **Color** 改成浅蓝色，整个空间开始偏冷；改成淡黄色，墙面立刻暖起来。

同一块地板，同一面墙，同一个发光球，只动一盏灯，感觉已经变了。

现在你有一个很重要的直觉：**物体的颜色由材质和光一起算出来，材质只决定其中一部分。**

## 颜色是物体、光、角度三者的结果

你看到一个物体呈什么颜色，由三样东西共同决定：

1. 物体表面材质的底色（`Albedo` / `Base Color`）。
2. 打在它身上的光是什么颜色。
3. 光以什么角度和强度照过来。

同一面米白墙壁，暖黄灯下偏奶黄，冷蓝月光下偏灰蓝。墙没动，光一变，情绪就变。

所以搭建空间时，**调材质和调灯光必须同时进行**。只盯着材质调，最后常常会发现「在 Scene 里好看，进 VRChat 之后怎么脏脏的」。原因可能在光：光把材质照坏了。

## 材质：物体的外衣

模型的形状由 Mesh（网格）决定，视觉外观由 Material（材质）决定。

同一个 Cube，穿上暗绿粗糙材质像铁盒，换成淡黄木纹像木料，换成半透明材质像玻璃。形状没变，观感完全不同。

:::::tip[为什么是这样？]
形状和表面视觉分开管理，是为了复用。一块古木材质可以同时用在大门、书桌、地板上；同一个球体可以套金属材质、玻璃材质、石头材质。拆开之后，你改材质不用重做模型，换模型也不用重调整套视觉参数。
:::::

## Material、Shader、Texture 是三层关系

你现在会看到三个词：`Material`、`Shader`、`Texture`。按这个顺序理解就行：

* **Shader**：一套渲染规则，告诉 GPU「这个表面要怎么被画出来」。
* **Material**：一份具体配置，记录颜色、金属感、光滑度、贴图等参数。
* **Texture**：贴图图片，比如木纹、砖缝、划痕、发光图案。

把它想成做饭：Shader 是做法，Material 是这一锅的调味比例，Texture 是具体食材的纹理。你平时最常直接操作的是 Material。

本书前期按 VRChat 世界项目里最常见的内置渲染管线来走。你可能在 Inspector 里看到 `Albedo`，也可能看到 `Base Map` / `Base Color`。名字不完全一样，作用接近：它们都在控制表面的基础颜色。

## 动手：给地板换件衣服

1. 在 Project 面板的 `Assets` 目录下新建文件夹 `Materials`。
2. 进入 `Materials` 文件夹，右键 `Create` → `Material`。
3. 命名为 `Mat_Floor_WarmGray`。
4. 选中这个材质球，在 Inspector 里找到 `Albedo`（或 `Base Map` / `Base Color`）。
5. 点色板，选一个偏暖的灰色。想精确一点，可以输入 `#8A8178`。
6. 把材质球从 Project 面板拖到 Scene 视图里的 `Floor` 上。

地板立刻变成暖灰色。你没有改 `Floor` 的形状，也没有改它的 Collider，只是换了它的表面视觉。

接着给墙壁也做一个材质：

1. 新建 `Mat_Wall_OffWhite`。
2. `Albedo` 输入 `#D8D2C4`。
3. 拖到 `Wall_Left` 和 `Wall_Right` 上。

如果你还有后墙，也一起拖上去。墙从冷白变成米白，房间会少一点「默认工程」的味道。

## 材质面板里先看四个参数

材质面板参数很多，初学只看四个：

* **Albedo / Base Color**：底色。初学阶段最常改这个。
* **Metallic**：金属感。`0` 是非金属，木头、布料、墙面都接近 `0`；`1` 接近纯金属。
* **Smoothness**：光滑度。低一点像水泥，高一点像抛光塑料或金属。
* **Emission**：自发光。适合霓虹、屏幕、发光符号。

这些参数基于 PBR（Physically Based Rendering，基于物理的渲染）。你不用懂公式，先记住一个工作习惯：**墙、地板、木头这类普通物体，Metallic 放 `0`，Smoothness 保持低值（0.1–0.3 之间）。**

给地板试一个安全值：`Metallic = 0`，`Smoothness = 0.25`。给墙试 `Metallic = 0`，`Smoothness = 0.15`。这两个数不神秘，只是一个不容易翻车的起点。

## 给发光球做一点颜色

现在轮到 `GlowBall`。

1. 新建材质 `Mat_GlowBall_Cyan`。
2. 把 `Albedo` 改成浅青色，输入 `#6EE7F9`。
3. 如果材质面板里有 `Emission`，勾上它，把颜色也设成 `#6EE7F9`。
4. 把材质拖到 `GlowBall` 上。

如果你勾了 `Emission`，球本身会看起来更亮。但要注意一件事：**自发光材质看起来会亮，不等于它真的照亮周围物体。** 照亮墙和地板，需要 `Light` 组件。

这也是很多人第一次做霓虹灯会卡住的地方：字牌亮了，墙没被照亮。因为材质和灯光是两件事。

:::::caution[踩坑预警]
如果某个材质突然变成刺眼的粉色，通常是 Shader 丢了、Shader 不兼容，或者项目渲染管线和材质来源对不上。选中材质，看 Inspector 顶部的 `Shader` 下拉框，先换回项目里稳定可用的标准材质 Shader。后面讲素材导入时会专门处理这类「粉色材质」问题。
:::::

## 初学阶段：先用纯色

纯色最容易控制整体基调：暖灰地板、米白墙壁、浅青发光球，三个颜色放在一起已经有了基本的气氛。木纹砖纹后面再加。

**先用纯色定冷暖，等氛围对了再细化材质。** 大关系先于细节，这是三维美术里很实用的顺序。

你现在可以把房间看成三块：

* 地板负责稳定感，颜色可以深一点、灰一点。
* 墙壁负责反光和背景，颜色可以浅一点、脏一点。
* 发光球负责焦点，颜色可以更明确。

这里说的「脏一点」，意思是避开纯白。纯白墙在强光下很容易刺眼，也会让空间像没有调过色的默认工程。

## Light：空间情绪的开关

材质决定物体表面是什么底子，Light 决定这个底子怎么被看见。

Unity 里常见的 Light 类型有几种：

* `Directional Light`：方向光，常用来模拟太阳或月亮。位置不重要，Rotation 才重要。
* `Point Light`：点光源，像灯泡，从一个点向四周发光。
* `Spot Light`：聚光灯，像手电筒或舞台灯，朝一个方向打出锥形光束。
* `Area Light`：面光源，适合柔和的大面积光，但通常需要烘焙进 lightmap，前期先知道有它就行。

这一章只动前两个：`Directional Light` 和 `Point Light`。够用了。

## Directional Light：全局日光

场景默认的 `Directional Light` 可以先当作太阳。它有一个特点：**位置无所谓，只有 Rotation 角度起作用。**

选中 `Directional Light`，把 Transform 的 Rotation 设为：

```text
X = 50
Y = -30
Z = 0
```

然后把 Light 组件里的参数调成：

```text
Color     #9AB4C8
Intensity 0.35
```

场景会变成偏冷的柔和底光。墙面和地板还能看清，但不再像正午白光直怼脸上。

X 轴角度控制太阳高度：`90` 接近头顶直射，`30` 更像低角度斜射。Y 轴角度控制水平朝向。你不需要一次记住所有角度，只要在 Scene 视图里旋转它，看阴影怎么移动。

:::::tip[为什么是这样？]
Directional Light 模拟很远的光源，比如太阳。太阳离我们太远，照到房间里的光可以近似看成同一个方向的平行光，所以 Unity 只关心它朝哪照，位置随便放。用位置控制太阳的话，每做一个大场景都得把「太阳」放到极远处，编辑很不方便。
:::::

## 阴影让空间站起来

把 `Directional Light` 的角度调低一点，你会看到墙角、球体、地板之间出现明暗关系。空间开始有前后、有重量。

阴影是大脑判断三维深度的重要线索。没有阴影的场景看起来像纸片，所有东西都浮在同一个平面上。斜角光会拉出长一点的阴影，立体感自然更明显。

但阴影也贵。Unity 的实时阴影需要每帧更新 shadow map。灯会动、物体会动、玩家也会动，阴影跟着算。学习阶段你可以开着看效果，真正做 VRChat 世界时要开始克制。

现在先用这个规则：**主光开阴影，装饰性小灯关掉阴影。**

## Point Light：局部暖光

`Point Light` 像一颗灯泡，光从中心向四周散发，距离越远越弱，超过 Range 后就不再照亮物体。

选中 `GlowBall`。如果它身上还没有 Light 组件，点 `Add Component`，搜索 `Light`，把 Type 设为 `Point`。

然后试这组值：

```text
Type      Point
Color     #FFE0B0
Intensity 2.5
Range     4
Shadows   None
```

Build & Test 进去看看。模型还是那几块 Cube，但冷灰蓝的全局背景加上角落里一抹暖光，已经有了「这里可以坐下来」的感觉。

这就是材质和灯光能做到的事：不写一行代码，只靠颜色和光，就能让空间传达情绪。

## 冷暖对比：最不容易翻车的一招

如果你面对色板不知道怎么选，直接套这个组合：**冷调全局光 + 暖调局部光**。

冷色全局光负责空气感，暖色局部光负责停留点。玩家走进房间时，会自然被暖光吸引，靠近那一块。你没有放箭头，也没有写提示，但光已经在引导动线。

反过来也可以：暖色夕阳铺满房间，角落里放一点冷蓝屏幕光。重点是让空间里有主次，配方可以换。

不同类型的世界，灯光服务的目标也不一样。休闲世界要让人放松，亮度低、对比柔，玩家才愿意久待。游戏世界要先保证识别，敌人、按钮、危险区必须看得清。展览世界更像博物馆布展，让作品本身做主角。同样是 `Light`，同一套参数面板，目的不同，填法就不同。

## 留一点暗部

新手很容易把每个角落都照亮，怕玩家看不清。

可以换个想法：亮暗之间的差别，才让人感觉「那里是角落」「这里是入口」「那边有东西」。所有地方一样亮，空间就平了。

你可以给房间留一点暗部。暗部也是构图的一部分。只要玩家该走的路、该点的按钮、该看的物体清楚，边缘暗一点反而更有层次。

一个简单检查方法：把 Scene 视图缩小一点，眯着眼看。你还能不能一眼看出哪里是视觉焦点？如果整个画面均匀发亮，说明灯太平均。

## VRChat 里要节制实时灯光

实时灯光的计算成本不低。场景里每多一盏实时 Point Light，显卡就多一份运行时计算；如果还开实时阴影，成本更明显。VRChat 又是多人场景，玩家的 Avatar、镜子、视频播放器、粒子特效都会抢同一份性能预算。

目前学习阶段，两三盏灯完全没压力。你先把效果做出来，理解光怎么影响空间。到后面的性能章节，我们会讲烘焙光照、Lightmap、Light Probe、Quest 版本怎么处理。

先记一个保守做法：

* 主要环境光用 `Directional Light`。
* 少量局部重点用 `Point Light`。
* 装饰性发光物体优先用 `Emission` 表现，不一定都要配实时 Light。
* 小灯默认不开阴影，除非它的阴影真的在服务体验。

Quest / Android 世界会更严格。官方优化建议里会反复提醒你控制材质、Shader、实时灯光和贴图成本。这些词后面都会讲到，现在只要知道：**好看的光可以先做出来，跑得动的光要靠后面那套优化方法。**

## 常见问题：我调了但看不出来

如果你改了颜色或灯光，场景里却没什么变化，按这个顺序查：

1. 材质有没有真的拖到物体上？选中物体，看 `Mesh Renderer` 里的 Materials 槽。
2. 你是不是还在 Play Mode 里调？退出 Play Mode 后改动会还原。
3. Light 的 Intensity 是不是太低？Range 是不是没覆盖到墙和地板？
4. 物体是不是被别的强光照满了？一盏很亮的 Directional Light 会盖掉小灯效果。
5. Scene 视图是不是开了某种调试显示模式？先切回正常 Shaded 视图。

排查视觉问题时先走这三步：确认「材质在不在」「灯照不照得到」「有没有另一盏灯把效果盖住」。多数初学阶段的问题到这里就能定位。

:::::note[AI 小助手]
问 AI 视觉问题时，把当前参数贴给它：Directional Light 的 Rotation、Color、Intensity；Point Light 的 Color、Intensity、Range；材质的 Albedo、Metallic、Smoothness。示范问法：「我在 Unity 做 VRChat 小房间，想要冷色月光 + 暖色角落灯。当前参数如下……你帮我指出哪几个值最可能让画面发灰？」让 AI 先分析参数，你自己回 Unity 里验证。
:::::

## 变式练习：做三个时间段

自己改三版光照，先做再对比：

1. **清晨**：全局光偏冷、强度低一点，局部暖光也低一点。
2. **午后**：全局光更暖、更亮，阴影角度斜一些。
3. **深夜**：全局光很低，局部灯成为主要视觉焦点。

每做一版都 `Build & Test` 进去站一分钟。只在 Scene 视图看不够，VRChat 世界最终是人站进去看的。你会发现有些在编辑器里「好像不错」的光，进 VR 后会太亮、太暗，或者方向怪。

再加一个小挑战：三个版本只改 Material 和 Light，模型保持原样。你会更清楚这两样东西的力量。

再往后，世界要开始「动」了。但在写代码之前，我们先花一小节把 Unity 这套「空壳加零件」的设计哲学理顺。理解了它，后面写脚本、做交互、查 bug，都会轻很多。
