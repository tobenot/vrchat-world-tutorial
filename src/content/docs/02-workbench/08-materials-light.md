你的第一个世界现在能正常跑起来了。里面有地板、有复制出来的几面墙壁，还有一个发光的小球。但如果你点击 Build & Test 走进去看一眼，大概会觉得哪里有些不对劲：灰白色的默认地板，雪白的墙壁，以及极其冷淡的默认天空。整个世界像是一个刚刚被拆掉脚手架的毛坯样板间，干净、空洞且毫无温度。

那些让你愿意长久停留的 VRChat 世界，无论是深夜雨中的暖光小屋、霓虹闪烁的未来街区，还是一家极其安静的多媒体美术馆，它们之所以能在一瞬间抓住你，很大程度上是因为：**在你走进去的那一秒，你的眼球和大脑就捕获到了某种极其强烈的空间氛围。** 至于玩法和交互机制，反而在其次。

氛围感究竟从哪来？其实绝大部分，都取决于两样东西：**Material（材质）**与**Light（灯光）**。

这一章我们的目标很小，就是让你亲身体会到：同一个物理空间，仅仅稍微改动一下颜色和光线的入射角度，它能传达出的情感氛围就会产生翻天覆地的改变。

## 颜色并不是物体身上写死的属性

在 Unity 编辑器中（其实在现实物理世界中也是如此），你看到一个物体究竟呈现出什么颜色，是由以下三样东西在视网膜上共同作用的物理结果：

1. **物体表面材质本身的色彩**（即材质的 Albedo / Base Color 基色）。
2. **当前正照在物体表面的光芒色彩**（光源本身的颜色）。
3. **光芒以什么角度和强度射向它**（光的入射角与衰减）。

同样一面涂满 Off-white（米白色）漆料的墙壁，在暖黄色的白炽灯下看起来像温馨的奶黄色，在冷蓝色的清冷月光下看起来则像幽暗的灰蓝色。墙壁本身的材质一动没动，但光芒一变，它呈现出的情绪感知就完全不同了。

理解了这一点，你就会明白为什么在空间搭建中，**调材质与调灯光必须是同时进行、相辅相成的。** 单独调其中一个而忽略另一个，都无法调配出高级的空间质感。

## 材质：赋予物体好看的外衣

在 Unity 中，模型的骨架和形状由 Mesh（网格）决定，但它的皮肤和视觉外观，则完全由 **Material**（材质）掌控。

同一个 Cube 立方体，穿上墨绿色的粗糙材质就像一个生锈的金属铁盒，换上淡黄色的木纹材质就像一块木料，而如果换上半透明材质，则像一块精致的无色玻璃。几何形状一字没改，但给人的心理暗示完全是两码事。

:::tip[为什么是这样？]
为什么在三维引擎中，形状（Mesh）和表面视觉（Material）要完全拆分开来独立管理？因为这能实现极高的复用效率。同一种材质（如一块斑驳的古木材质球）可以穿在不同的几何体上（大门、书桌、地板）；而同一种形状（如一个 Sphere 球体）也可以套用不同的材质球（金属球、玻璃球、石头球）。这种拆分管理，让你可以极度自由地排列组合。
:::

## 动手做一个材质：给你的地板换件衣服

现在，我们给光秃秃的灰白色地板换上漂亮的新衣裳：

1. 在 Project 面板的 Assets 目录下，新建一个专门存放材质的文件夹，命名为 `Materials`（右键 → `Create` → `Folder`）。
2. 在该文件夹内，右键选择 `Create` → `Material` 新建一个材质球。给它起一个优雅的名字，比如 `Mat_Floor_WarmGray`。
3. 鼠标选中这个新建的材质球，右侧 Inspector 面板中会出现一大堆密密麻麻的调节参数。请不要惊慌，现在只寻找一栏叫做 **Albedo**（或在部分新版本中叫做 `Base Map` / `Base Color`，它们都代表着材质最基础的表面颜色）。
4. 点击它旁边的色板弹窗，用吸管或调色盘选定一个偏暖调的灰色（如果你想追求极其精确的高级感，可以尝试输入十六进制色值 `#8A8178` —— 这是一种带有呼吸温度的浅暖灰）。
5. 在 Project 面板中按住这个材质球，**直接用鼠标拖拽**到主场景的 `Floor` 物体上。

松开鼠标的一瞬间，你会发现脚下的地板立刻变成了一个非常有质感的暖灰色。给物体上材质，其实就是这么简单。

## 材质面板下的四个黄金参数（先了解，不急着动）

当你选中刚才的材质球，你会发现在 Albedo 基色下方，还有几个控制视觉质感的核心滑条：

* **Metallic**（金属感）：滑条在 0 到 1 之间。0 代表完全的非金属（如木头、棉布、泥土），1 代表镜面般纯粹的金属（如不锈钢、金、铝）。
* **Smoothness**（光滑度）：控制表面的反光聚散。0 代表极度粗糙（如粗糙水泥墙、砖块），光线射上去会彻底散开；1 代表完美的抛光镜面，能映射出清晰的环境反射。
* **Normal Map**（法线贴图）：这是一样极其神奇的二维贴图。它能用最少的性能成本，在原本平坦的模型表面上，“凭空”模拟出砖缝、木头纹理、金属划痕等令人惊叹的凹凸细节。
* **Emission**（自发光）：勾选后，材质本身会像显示器、霓虹灯管或萤火虫一样，在黑暗中自己散发出特定颜色的微弱光芒。

:::tip[为什么是这样？]
这些精细的材质滑条参数，在工业界源自一个统一的技术标准，叫做 **PBR**（Physically Based Rendering，基于物理的渲染）。简单来说，Unity 会在底层通过极其精密的数学公式，模拟现实世界中光线在不同微观介质表面发生的折射、散射与反射行为。你不需要懂得任何高深的物理公式，只需要用直觉拖动 Metallic（金属感）与 Smoothness（光滑度）两个滑条，就能在屏幕上轻松配制出塑料、金属或石头的感觉。
:::

## 极简美术原则：大关系（颜色）先于小细节

在搭建世界的初学者阶段，请极力强迫自己**只使用纯色材质球**。不要一上来就急着贴木纹贴图、砖墙纹理等。

因为纯色是最容易在第一眼控制空间整体基调的。你用高级暖灰色铺设地板，用温馨的米白色铺设墙壁，角落里点缀一个浅蓝色的发光球。仅仅这三个颜色放在一起，就已经在视觉上显现出了一个极其雅致的小屋雏形。

而如果你一上来就急着塞满各种细节粗糙、色彩各异的免费木纹贴图，反而会把整个空间的色彩和视觉重心搞得极度凌乱。

**先用纯色定好大的冷暖氛围，等氛围完全对了，再逐步去细化材质细节。** 这是所有三维美术设计中通用的大师级原则：大关系永远先于细节。

让我们给墙壁也做一个材质。命名为 `Mat_Wall_OffWhite`，将 Albedo 颜色设为偏暖的米白（色值 `#D8D2C4`）；再给 GlowBall 制作一个专属材质，命名为 `Mat_GlowBall_Cyan`，颜色设为晶莹剔透的浅蓝绿（色值 `#6EE7F9`）。

将它们分别拖拽到场景里的墙壁和球体上。看着这三个颜色在场景中和谐交织，你是不是觉得，这栋灰白毛坯房瞬间变得有一点点设计工作室的质感了？

## 太阳灯（Directional Light）：掌控全局的日光

材质赋予了表面好看的底色，但唯有当光芒射向它们时，这些底色才能被我们的眼球捕获。

场景中默认存在的那一盏 `Directional Light`（平行光）就像是挂在天上的太阳。它拥有一个非常奇妙的引擎特点：**它的位置在哪一点都不重要，起决定性作用的是它的 Rotation 旋转角度。**

无论你把这盏灯移动到场景的哪个遥远角落，它照下来的平行光轨迹都不会发生一丝位移。但一旦你尝试旋转它的角度（例如修改 Rotation 的参数）：

* **X 轴角度**控制太阳的俯仰高度：当 X = 90 时，代表正午时分太阳从头顶垂直直射下来；当 X = 30 时，代表低角度斜射，能瞬间拉出极长的斜阳，营造出落日黄昏的唯美意境。
* **Y 轴角度**控制太阳在水平方向上的旋转偏向。

选中你场景里的 Directional Light，将 Rotation 设为 `50, -30, 0`，并将 Intensity 强度从 1 降为 `0.6`。

观察一下画面，场景是不是在一瞬间就有了极其唯美的午后立体感？地板上被拉出了错落有致的墙角阴影，物体的侧面由于光照角度呈现出了明暗过渡，空间一下子变得极富层次。

:::tip[为什么是这样？]
为什么旋转了光的角度、拉长了阴影后，画面会立刻显得高级且富有立体感？因为阴影是人类大脑感知三维体积和空间距离最重要的一条“物理线索”。如果场景中没有阴影，大脑就会失去对深度（Depth）的判断，东西看起来就会像纸片一样干瘪、扁平。这也正是为什么无数资深关卡设计师在设计光影时，都极力追求斜角射光的原因。
:::

## 局部灯（Point Light）：制造温暖角落的魔术师

如果说 Directional Light 是负责照亮整片大地的太阳，那么 `Point Light`（点光源）则是放在屋子里的一颗温暖白炽灯。它具有强烈的距离衰减属性，只能照亮它周围一圈有限的空间。

你可以选中 `GlowBall` 身上的 Point Light 组件，尝试去微调它的各个核心参数：

* **Color**（颜色）：直接控制灯泡散发出的色彩基调。浅蓝色能瞬间给房间罩上一层神秘、科幻的冷调；暖黄色则像一盏床头灯，能迅速融化空气里的冰冷。
* **Range**（范围）：光的照射范围。将它设在 3 到 6 之间，非常适合营造一个精致、局部的光照角落，能避免光芒穿透到墙壁之外。

:::note[不同世界不同活法]
在搭建不同类型的 VRChat 世界时，光的运用方式也会截然不同。在追求温馨治愈、供朋友围炉夜话的「休闲世界」里，创作者通常会狠心关掉全局明亮的太阳灯，转而在不同角落里放置多盏低强度、高 Range 范围的暖色点光源，营造出极其放松的环境声响；而在需要射击、攀爬或寻找线索的「游戏世界」里，为了保证玩家能看清前方的每一个障碍物，创作者则会使用明亮均匀的平行光，确保全图没有过于死暗的性能盲区。
:::

## 极简配光神技：冷暖色彩对比原则

如果你在面对一堆色板时觉得大脑一片空白，不知道该如何给你的小屋配光，请直接套用这套在视觉艺术里深耕了数百年的经典神技：**「冷调全局光 + 暖调局部光」**（或反过来）。

尝试将你的全局平行光（太阳）设为偏冷的淡蓝灰（色值 `#9AB4C8`），强度设为极弱的 `0.3`。然后，将角落里 `GlowBall` 身上的点光源设为极其温馨的暖黄色（色值 `#FFE0B0`），强度设为 `2.5`。

按下 Build & Test 进去体验一下。

你会发现模型依然是那几块 Cube，但此时的小屋已经展现出了极其动人的画面情绪：冷灰蓝的全局背景色让你的内心瞬间平静下来，而角落里那一抹跳跃着的、温馨的橙黄色暖光，则像是在深夜黑夜里点燃的一簇篝火，指引并暗示着玩家：这是一个可以安心坐下来和朋友倾心交谈的舒适港湾。

这就是材质与灯光交织出的空间魔法。它不需要你写哪怕一行复杂的逻辑代码，就能用最纯粹的视觉直觉，在进门的第一秒就牢牢俘获玩家的内心。

## 关于光照性能的初步预警

在这一章的末尾，我们需要在你的工具箱里，提前放下一颗非常重要的性能警示炸弹：

**在三维引擎中，实时动态灯光（Realtime Lights）的计算成本是极其昂贵的。**

你在场景里每多放置一盏实时的 Point Light，玩家电脑的显卡在每一帧画面渲染时，就要把周围物体的阴影和光影过渡重新进行一次极其繁重的数学计算。在多人在线的 VRChat 中，为了保证中低配玩家在进入你世界时不发生卡顿，我们必须节制地使用实时灯光。

当然，在目前的学习第一阶段，我们在屋里放置两三盏实时灯是完全不会有任何性能压力的，你可以放心地折腾。在以后的进阶章节中，我们将学习如何将精致的灯光烘焙成贴图以拯救性能，如何制作一面能照出人影的镜子，甚至是针对 Quest 移动端进行极限画质优化。

第二部「认识你的工作台」到这里就完美落幕了。你已经光荣地征服了 Unity 工作台上最核心的五大王牌基石：

* **GameObject**（游戏物体）：一切皆物体的空壳世界。
* **Component**（组件）：赋予物体十八般武艺的能力积木。
* **Prefab**（预制体）：高效率一键全局同步的生产模具。
* **Material**（材质）：给物体穿上不同物理质感的好看外衣。
* **Light**（灯光）：烘托空间情绪、赋予画面深度与层次感的灵魂开关。
