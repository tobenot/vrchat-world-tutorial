:::note[本地与共享范围]
本部自定义脚本主要修改当前客户端的状态。例如一位玩家按下灯开关，其他客户端的灯不会自动跟着变化。SDK 组件也各有自己的行为范围；需要共享的门状态、物理状态或颜色必须分别明确同步方案，不能由单人测试推定多人一致性。
:::
