第二部把房间搭起来，第三部把脚本读懂。但房间到这里还是静的：门是装饰，按钮按了没事，球放在桌上不会被拿起来。

第四部专门补这块。每一章只做一件事，一个晚上能做完，做完场景里多一个「会动的」对象。五个动手章 + 一节理解章 + 一节创作者视角。

读完这一部，能拿到的：一个有按钮、有触发区域、有可拿起物体、有座椅镜子和传送点、有可开关门的房间；以及一份「事件 → 条件 → 动作」的拆解视角，看任何 VRChat 世界都能猜出大半结构。

读完之后再去第五部选方向，不同类型的世界把这些积木拼出完全不同的东西。

:::note[关于多人同步]
这一部的所有交互都按「单人本地」做。两个朋友同时进世界时，会出现「你这边灯亮了对方那边没亮」这类现象。这不是 bug，是同步要单独学一遍。第六部专门讲多人同步。先把单人版做扎实，到时候再补同步只是给现成脚本加几行字段。
:::
