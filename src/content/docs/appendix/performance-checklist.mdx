## 计划骨架

填充后大致结构：

### G.1 通用性能（PC + Quest 都看）

- [ ] Draw Call 数量（< X 个）
- [ ] 实时灯光数量（< X 盏）
- [ ] 实时投影灯光数量（< X 盏）
- [ ] 镜子是否默认禁用 / 玩家手动启用
- [ ] 静态物体是否标记 Static（让 Static Batching 生效）
- [ ] 大场景是否做了 Occlusion Culling

### G.2 Quest 专项

- [ ] 实时灯光 ≤ X 盏
- [ ] 不使用不在 Quest 白名单上的 Shader
- [ ] 贴图最大尺寸 ≤ X
- [ ] 单个材质贴图数量
- [ ] 总体面数
