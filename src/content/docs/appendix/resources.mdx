## 可学习的示例项目

| 入口 | 用法 |
|---|---|
| UdonExampleScene（SDK 自带） | VCC 创建新项目时包含的官方示例场景。覆盖 Interact、Pickup、同步等基础交互，是拆解学习的第一站 |
| [GitHub 搜 `udonsharp`](https://github.com/search?q=udonsharp&type=repositories) | 大量开源 UdonSharp 项目。按 Star 排序能找到社区认可度高的参考实现 |
| [VRChat 官方 GitHub 模板](https://github.com/vrchat-community) | 官方维护的世界模板和工具，代码质量有保障 |

读别人的代码是学编程最快的方式之一。进到一个喜欢的开源世界，把它的 UdonSharp 脚本拆开看，比从零写更容易建立心智模型。
