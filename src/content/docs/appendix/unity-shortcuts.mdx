## 主面板分工

| 面板 | 默认位置 | 干什么 |
|---|---|---|
| `Scene` 视图 | 中央上 | 三维搭建画布 |
| `Game` 视图 | 中央上（标签切换） | 模拟玩家相机视角 |
| `Hierarchy` | 左 | 当前场景所有 GameObject 的目录 |
| `Inspector` | 右 | 选中物体的所有组件和参数 |
| `Project` | 下方 | 项目所有资产文件夹 |
| `Console` | 下方（标签切换） | 报错、警告、Log |

详见 [第 4 章 · 第一次面对 Unity](/getting-started/tools/#第一次面对-unity)。
