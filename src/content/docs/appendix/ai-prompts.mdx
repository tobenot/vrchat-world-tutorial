## I.1 翻译官方文档

读 VRChat 或 Unity 官方英文文档觉得吃力时：

```text
我刚开始做 VRChat 世界。下面这一段来自官方文档：

[贴原文段落]

请用大白话告诉我：
1. 这东西干嘛用
2. 我现在最该关心的三个字段是哪几个
3. 不动它会怎样
```

来源：[第 3 章 · AI 小助手](/getting-started/ai-partner/#把答案当假设不当结论)。

## I.2 解读 Console 报错

```text
我在 Unity 项目（Unity 版本 X，VRChat SDK 版本 Y）里 Build & Test，Console 出现这条红字：

[完整粘贴报错]

相关代码（如果是脚本报错）：

[贴出报错指向的代码段]

请说：
1. 这个错可能是 A，也可能是 B，分别怎么验证
2. 在我贴的代码里能直接看出问题吗
3. 如果不能，我下一步该看什么
```

来源：[第 3 章](/getting-started/ai-partner/#把答案当假设不当结论)。

## I.3 写第一版脚本草稿

把模糊需求拆成最小版本：

```text
我用 Unity 和 UdonSharp。我想做 [一句话描述需求]。

约束：
- 先不要动画 / 平滑过渡
- 先不要音效
- 先不要多人同步
- 我要能跑起来的最小版本

请告诉我：
1. 场景里要建什么 GameObject
2. 每个物体挂什么组件
3. 脚本继承自 UdonSharpBehaviour，请把它的代码写出来
4. 怎么测：在编辑器里按什么、看什么变化
```

来源：[第 3 章 · 让它先做最小的那个](/getting-started/ai-partner/#让它先做最小的那个)。

## I.4 调材质 / 灯光参数（视觉问题）

```text
我在 Unity 做 VRChat 小房间，想做出 [冷月光 / 暖咖啡馆 / 夜霓虹 等] 的氛围。

当前参数：
- Directional Light: Rotation X=__, Y=__；Color #__；Intensity __
- Point Light（数量 N）: Color #__；Intensity __；Range __
- 主要材质 Albedo / Metallic / Smoothness：__

请指出哪几个值最可能让画面偏 [灰 / 平 / 死板 / 刺眼]。先分析参数，再给改值方向，不要直接改我的代码。
```

来源：[第 9 章 · AI 小助手](/workbench/materials-light/#调了但看不出来时)。

## I.5 按组件思路排查 bug

```text
我在 VRChat 世界里做了 [一个按钮 / 一扇门 / 一个 Pickup 物件]。

物体上挂的组件：
- [列出所有组件]

引用槽 / 关键字段：
- [列出引用槽连接情况]

期望行为：[描述]
实际行为：[描述]

请按"组件 → 引用 → 事件流"的顺序帮我列检查清单。
```

## 通用注意

无论哪个模板，都遵循：

- 把 Unity 版本 / SDK 版本 / 平台（PC/Quest）告诉它，避免它给跨版本的过期答案。
- 让它先**分析**再**给方向**，不要直接让它改代码。
- 拿到答案后回 Unity 自己跑，跑通了才算。
- AI 给的组件名 / API 名要先在 SDK 控制面板或 `Add Component` 里搜一下，搜不到大概率是它编的（[第 3 章](/getting-started/ai-partner/#它会什么不会什么) 已经说明）。
