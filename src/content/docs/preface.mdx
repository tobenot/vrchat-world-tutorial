本书面向制作 VRChat 世界的人，不要求已有 Unity、C# 或 Udon 开发经验。

VRChat 世界由场景资源、组件和脚本共同组成。模型、材质与灯光决定画面；Collider 定义碰撞或检测范围；交互事件把玩家操作传给脚本；网络同步把需要共享的状态传给其他客户端。静态场景可以独立构成完整作品，是否加入交互由世界的用途决定。

## 内容范围

本书收录工具安装、场景搭建、UdonSharp 编程、多人同步、空间设计、性能测量、发布与维护。正文中的操作步骤包含目标对象、字段设置、代码和预期结果；附录提供术语、组件、错误信息与检查清单。

本书围绕 VRChat 世界开发选取内容。完整接口定义以 VRChat Creator Docs 为准；Unity 通用功能和 C# 语法分别以 Unity 与 Microsoft 文档为准。

## 如何验证示例

核对示例使用的 Unity 与 SDK 版本，按步骤设置场景，然后比较实际结果与测试条件。编译错误查看 Console；运行结果不符时，分别检查组件是否启用、引用是否赋值、事件是否执行，以及状态是否需要网络同步。

ClientSim 适合在编辑器里检查部分交互。客户端行为使用 Build & Test 核对；多人同步和跨平台差异需要相应客户端或设备测试。一次本地测试不能代替这些验证。
