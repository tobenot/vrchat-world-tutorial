VRChat 里有一些世界，地板踩上去会泛光，手挡住光带时有体积光泛起。雨滴打在铁皮屋顶上真有声音和对应的溅射。挥一下剑砍在墙上，手柄居然会震。

你也许亲身见过，也许只是从朋友那儿听说。重要的是，你现在想做一个。

「这是怎么做出来的？」

打开浏览器一搜，Unity、C#、SDK、Udon、同步、网络变量，一堆词扑面而来。教程散落各处：有的在视频站深处，有的是三年前的视频，评论区还有人写「这方法已经不能用了」。跟着做了一半迷路，或者看了第一页就关掉，都很正常。

这本书就是写给此刻坐在这里、想做一个世界的你的。

你的背景不重要。玩了很久还是昨天刚下载 VRChat，想做朋友窝着的小屋还是脑子里有个宏大的游戏想法，会不会写代码，都没关系。我先假设你啥都不会，然后一步一步地，像你坐在旁边我指着屏幕跟你讲一样，走到你自己做了一个世界、拉朋友进来转了一圈的那天。

## 这本书做一件事

把碎在十几个地方的知识铺成一条路。

它不替代 API 文档，接口说明用到了再翻官方的；也不替代系统的 Unity 教材或 C# 语言课，那些各有专门资源。你的目标更具体：做 VRChat 世界。所以书里砍掉了暂时用不上的内容，只留你眼下需要的。

## 读完你会做到什么

具体到能交出来的东西：

- 一个 VRChat 世界从 Unity 场景到玩家面前的全程，你会走完一遍。
- 按钮、门、拾取物、触发区域这些基础交互，你能自己做一遍。
- 多人同步那块为什么会让人头疼，你会知道从哪些小实验开始拆它。
- 怎么让一个空间像一个地方，而不只是几堵墙摆在那里，你心里会有方向。
- 发布之后怎么维护、更新、继续学，路是通的。

先站进去，再慢慢把门后的东西看清楚。
