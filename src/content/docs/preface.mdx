VRChat 里有一些世界，地板踩上去会泛光，手挡住光带时有体积光泛起。雨滴打在铁皮屋顶上真有声音和对应的溅射。挥一下剑砍在墙上，手柄居然会震。

见过这一类世界的人，或者听朋友说起过的人，常常会在某一刻停在同一个问题上：

「这是怎么做出来的？」

打开浏览器一搜，Unity、C#、SDK、Udon、同步、网络变量，一堆词扑面而来。教程散落各处：有的在视频站深处，有的是三年前的视频，评论区还有人写「这方法已经不能用了」。跟着做了一半迷路，或者看了第一页就关掉，都很正常。

这本书写给此刻在屏幕前、想动手做一个 VRChat 世界的人。

背景不重要。玩了很久还是昨天刚下载 VRChat，想做朋友窝着的小屋还是脑子里有个宏大的游戏想法，会不会写代码，都不影响往下读。本书默认零基础起步，从装工具开始，一步步走到把自己做的世界上传到 VRChat 这件事真的发生为止。

## 这本书做一件事

把碎在十几个地方的知识铺成一条路。

它不替代 API 文档，接口说明用到再翻官方的；也不替代系统的 Unity 教材或 C# 语言课，那些各有专门资源。本书的目标更具体：做 VRChat 世界。所以砍掉了暂时用不上的内容，只留眼下需要的。

## 读完会拿到什么

按章顺序读完，预计能拿到这些东西：

- 一个能上传到 VRChat 的最小世界（地板、出生点、Scene Descriptor）。
- 一组写过、调通过的基础交互范本：按钮、门、拾取物、触发区域。
- 一份关于多人同步问题的拆法清单：遇到「自己看到、朋友看不到」时，知道从哪几个小实验开始查。
- 一份空间体验检查项：让一个场景读起来像一个地方，而不只是几堵墙。
- 发布、更新、维护的基本流程，以及之后继续学习的方向。
