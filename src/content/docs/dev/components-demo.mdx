## 1. Steps：教程步骤

`<Steps>` 把有序列表渲染成带圆点编号的步骤条，比纯 `1. 2. 3.` 更醒目。

<Steps>

1. 在 VCC 中用 Worlds 模板创建项目。
2. 等待 VCC 安装依赖，再用指定的 Unity 编辑器打开项目。
3. 菜单栏 `File → New Scene`，选 `Basic`，按 `Ctrl+S` 命名 `MyFirstWorld`。
4. Hierarchy 右键 `3D Object → Cube`，缩放成 `10, 0.2, 10` 当地板。

</Steps>

## 5. Aside（提示框）：四种语义

Markdown 简写优先，组件式备用。

:::note[note 信息]
中性的补充说明，常用来引出"扩展阅读"。
:::

:::tip[为什么是这样？]
讲设计原理、对比"如果不这样会怎样"。这是本书的高频侧栏。
:::

:::caution[版本与字段差异]
具体到哪个按钮、哪个字段。如果 Unity 版本和教程不一致，容易在这里对不上。
:::

:::danger[数据与构建风险]
真的会让数据丢失或上传失败的硬错误，留给极少数情况。
:::

如果想用组件式（更灵活的标题与子内容），用 `<Aside>`：

<Aside type="tip" title="组件式 Aside（仅 MDX）">
  组件版可以在标题里嵌徽章、子组件，比 Markdown 简写更灵活。
</Aside>

## 6. 代码块标记（Expressive Code）

只在 `\`\`\`lang` 之后追加 meta 信息即可，无需任何额外组件：

```cs title="LampToggle.cs" {3-5} ins={6-7} del={8} collapse={1-1}
using UdonSharp;
using UnityEngine;
public class LampToggle : UdonSharpBehaviour {
    public Light targetLight;
    public override void Interact() {
        targetLight.enabled = !targetLight.enabled;
    }
    // ↑ 这两行被高亮为「新增」
    public AudioSource clickSfx; // ↓ 这行高亮为「删除」
    public string legacyTag;
    // ↓ 默认折叠的样板代码
    private void OnEnable() {}
    private void OnDisable() {}
}
```

**Meta 速查表**

| 写法 | 作用 |
| :--- | :--- |
| `title="…"` | 加文件名标题栏 |
| `{3-5}` | 高亮第 3–5 行 |
| `ins={6-7}` | 标为绿色「新增」 |
| `del={8}` | 标为红色「删除」 |
| `collapse={10-30}` | 默认折叠，点击展开 |
| `"关键词"` | 把行内某段词高亮 |
| `frame="terminal"` | 把代码块伪装成终端 |
| `frame="none"` | 关掉边框 |

## 9. Mermaid：图

无需额外组件，本项目已注入 Mermaid 客户端运行时。直接写 `<div class="mermaid">…</div>` 即可。

<div class="mermaid">
flowchart LR
  A[Unity 场景] --> B[VRChat SDK 包装]
  B --> C[Build & Test 本地预览]
  B --> D[Build & Publish 上传]
  D --> E[(VRChat 服务器)]
  E --> F[玩家在客户端进入]
</div>

  服务器-->>客户端: 返回 AssetBundle
  客户端->>玩家: 加载并渲染

## 10. 代码块标题 + 行号 + 关键字高亮

```cs title="仅供 Owner 执行的本地开关片段" showLineNumbers
public override void Interact() {
  if (Networking.IsOwner(gameObject)) {
    targetLight.enabled = !targetLight.enabled;
  }
}
```
