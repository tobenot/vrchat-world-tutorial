# 1. 一个玩家的好奇心

你最开始想做 VRChat 世界，大概是因为你在某个世界里停了下来。

也许是一间雨夜小屋。窗外有雨，屋里有暖光，朋友坐在地毯上聊天。也许是一个游戏世界，机关、计分、复活点、音效全都刚刚好。也许只是一个很小的角落，但你忽然想知道：

> 这个地方，到底是怎么被做出来的？

这一章先不急着打开 Unity。我们先把那个好奇心留住，然后看看它到底指向什么。

## 你想做的事，人类做了很久

你可能觉得"做一个 VRChat 世界"是一件很新的事情。某种意义上确实是，VRChat 2017 年才上线。但你想做的事情本身，人类做了几万年。

洞穴壁画。人在墙上画出猎物和手印，让后来的人走进去看到一幅景象。

神庙和教堂。空间本身就在传达信息：穹顶多高，光从哪里落下来，人走进去该感到什么。

花园和庭院。一个被精心安排过的地方，走进去能让人安静下来。

游乐园。一条被设计过的路线，每个转角藏着不同的体验。

游戏关卡。设计师用地形、光线、敌人的位置引导玩家走向特定方向，感受特定节奏。

VRChat 世界是这条线上最新的一环。你在做的事情，本质上跟建筑师、花园设计师、游乐园工程师、游戏关卡设计师做的事情是同一件：**构造一个别人可以走进去体验的环境。**

区别在于：VRChat 世界是虚拟的、多人的、可交互的，你一个人在家用电脑就能做。门槛前所未有地低。但你要面对的核心问题跟那些前辈一模一样：这个空间给人什么感受？人进来之后知不知道该往哪里走？他们愿不愿意留下来？

这是一种创作表达。你要创造的是**一个别人可以走进去存在的地方**。

## VRChat 世界不是普通地图

在很多游戏里，地图只是玩法的容器。但在 VRChat 里，一个世界本身就可以是作品。

它可以是房间、舞台、展厅、游戏、工具、故事，也可以只是一个让人愿意安静待着的地方。

这意味着，做 VRChat 世界同时涉及好几件事：

- 空间：人从哪里出生，往哪里走，停在哪里；
- 视觉：光、材质、颜色和构图；
- 声音：脚步、环境音、反馈音；
- 交互：按钮、门、拾取物、触发区域；
- 网络：你看到的东西，别人是否也看得到；
- 性能：好看，但也要跑得动。

听起来很多，对吧？没关系。我们不会一口吞完。

但我现在告诉你这些，是想让你知道一件事：**你学的是怎样创造一种体验。** 每一个工具和概念都服务于这个目标。以后遇到枯燥的技术细节，想想那个雨夜小屋，想想你心里那个画面。它就是你的方向。

## 一个世界由什么构成

在你学会怎么做之前，先有一个粗略的全景图会很有帮助。一个 VRChat 世界从你的电脑到别人面前，大概经过这些层：

1. **Unity 场景** — 你在 Unity 编辑器里搭建的三维空间，包含物体、灯光、脚本
2. **VRChat SDK** — 一组工具和组件，告诉 VRChat："这个 Unity 场景是一个世界"
3. **构建和上传** — 把场景打包，上传到 VRChat 服务器
4. **玩家加入** — 别人在 VRChat 客户端里找到你的世界，走进来

你以后会非常详细地了解每一层。现在只需要知道这个链条存在就行。

🤔 **为什么是这样？** 为什么不能直接用某种简单编辑器？因为 VRChat 世界需要三维渲染、物理模拟、脚本逻辑、网络同步。这些事情 Unity 已经做了二十年了，VRChat 没必要重新发明轮子。SDK 是一座桥：把 Unity 的能力接到 VRChat 的多人系统上。

## 先做出来，再理解

这本书的路线很简单：先让你站进自己做的世界里。

我们会先装工具、建项目、放地板、放出生点、Build & Test，然后你就能真的站进去。

等你已经看见结果了，再回头解释：刚才 Unity 做了什么，VRChat SDK 做了什么，为什么那个出生点决定了你进入世界时站在哪里。

但跟纯粹的"照着做"不同：每次动手之前，你会知道自己在解决什么问题。"你想站进自己做的空间里对吧？那我们需要解决三件事：有一块地面、有一个出生位置、有一个告诉 VRChat 这是世界的标记。来，逐个搞定。"

你不需要一开始就懂全部。你只需要知道自己在往哪走。

## 关于害怕和焦虑

如果你打开 Unity 看到一整面面板就想关掉，这是正常的。

如果你看到 C# 代码觉得自己永远学不会，这也是正常的。

这东西确实反直觉。好多地方确实设计得让新手困惑。问题在工具，不在你。

但也有一个好消息：几乎所有做出好世界的人，都经历过同样的阶段。那个在排行榜上的热门世界的作者，他第一天也是对着空白场景发呆的。他跟你唯一的区别是：他扛过了前面几周的困惑期。

这本书会帮你扛。碰到真难的地方我会直说"这块确实容易懵，我们一块一块拆。"碰到常见的坑我会提前告诉你"看看是不是这个原因。"

你不是一个人在做这件事。

## 这一章你要带走的东西

- 你在学的是怎样创造一个别人可以走进去体验的空间，远超"一个技术"。这件事人类做了几万年，你是最新的接力者。
- VRChat 世界开发会同时涉及美术、设计、脚本、网络和性能，但可以拆成一小步一小步学。
- 一个世界从你的电脑到别人面前：Unity 场景 → SDK 标记 → 打包上传 → 玩家加入。
- 卡住了是正常的。每个人都卡过。这本书会帮你扛过去。
