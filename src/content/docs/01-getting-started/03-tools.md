这一章我们将正式把工具安装好。

你可能想立刻打开 Unity 动手搭建世界，但 VRChat 开发有一条铁律：**版本必须配对。** Unity 版本、VRChat SDK 版本以及项目模板三者必须契合。如果版本对不上，后面会遇到各种诡异的编译报错，且很难定位原因。

最省心也最标准的路线，就是跟着官方的 VRChat Creator Companion（简称 VCC）走，由它来替你统一管理所有的工具版本。

## 工具链全景图

在开始下载之前，我们先来了解你即将用到的几样工具，以及它们各自扮演的角色：

```text
VRChat Creator Companion (VCC)
  │  项目管家：创建项目、管理 SDK 包、提醒更新
  │
  ├─► Unity Hub
  │     安装和管理不同版本的 Unity 编辑器
  │
  ├─► Unity Editor (Unity 编辑器)
  │     你真正搭建世界的工作台：摆放物体、调整灯光、编写交互
  │
  └─► VRChat SDK - Worlds
        安装在 Unity 项目里的一组专用包，让场景能被 VRChat 识别
```

你可以把这个关系形象地比喻为：VCC 是你的施工队领班，Unity Hub 是工具存放柜，Unity Editor 是你的工作台，而 VRChat SDK 则是放在工作台上的一套专业级特定改装工具。

:::tip[为什么是这样？]
为什么需要这么多层关系？因为 VRChat 借用了 Unity 这款深耕二十年的游戏引擎做底座。VRChat SDK 负责把 Unity 的三维渲染、物理和脚本能力接到 VRChat 的多人系统上。VCC 则确保两头的版本对齐。
:::

## 第一步：下载并安装 VCC

请打开 VRChat 官方创作者文档网站：[creators.vrchat.com/sdk](https://creators.vrchat.com/sdk/)。

在页面中找到并下载 **VRChat Creator Companion** 的安装包，按照默认指引安装。打开 VCC 后，它会提示你登录你的 VRChat 账号，直接登录即可。保持登录状态非常重要，因为后续的本地测试（Build & Test）以及发布世界都需要验证你的账号状态。

此后，当你需要打开或更新项目时，都请务必从 VCC 启动，它会自动帮你检测 SDK 的版本对齐情况。

## 第二步：安装官方指定版本的 Unity

这一步是重中之重：**你必须安装 VRChat 官方指定的那个精确的 Unity 版本。**

VRChat 对 Unity 的版本控制很严格。如果版本装错（哪怕只是最后一位不对），轻则 SDK 无法正常工作，重则项目文件损坏。

正确且安全的安装做法：打开官方版本说明页面 [Current Unity Version](https://creators.vrchat.com/sdk/upgrade/current-unity-version/)，确认当前官方指定的是哪一个版本。

然后，在 Unity Hub 中安装**完全一致的精确版本**。在安装模块时，默认勾选 Windows 平台的基础编译支持即可。

:::caution[踩坑预警]
Unity 的版本号非常长，例如 `2022.3.22f1`。请注意，最后的 `f1` 也是版本号的一部分。如果你错装了 `2022.3.21f1` 而不是 `2022.3.22f1`，项目依然可能报错。请确保安装的版本与官方网页上的字符逐字对齐。此外，后续如果你想让世界支持 Quest 或手机端，随时可以在 Unity Hub 里给当前版本「添加模块（Add Modules）」并勾选 Android 支持，不需要重新下载整个 Unity。
:::

## 第三步：用 VCC 创建你的第一个世界项目

打开 VCC，进入 Projects（项目）页面，点击创建新项目。项目模板类型请务必选择 **World**（世界项目，另一个 Avatar 模板是用来制作人物模型的）。

将项目命名为一个小写英文字符为主的名字，比如 `MyFirstWorld`。在电脑中选择一个专门存放项目的空目录，例如 `D:\VRChatProjects\MyFirstWorld`。

点击创建后，VCC 就会在后台自动为你下载并搭建好一个干净的、导入了最新版 Worlds SDK 的 Unity 项目。

:::tip[为什么是这样？]
为什么项目路径有一些奇怪的限制？因为 Unity 底层有很多文件读写逻辑，使用中文路径（如 `D:\我的项目\`）或过长的目录结构极其容易触发 Windows 的 256 字符路径长度限制，或者导致编码冲突。此外，请务必避开网盘同步目录（如 OneDrive、Google Drive）以及桌面，网盘的实时后台同步会和 Unity 的文件监视机制产生严重冲突，导致项目崩溃。
:::

## 第四步：首次打开项目并进行安全检查

在 VCC 的项目列表里找到刚刚新建的 `MyFirstWorld`，点击右侧的打开按钮，启动 Unity 编辑器。

由于是第一次打开，Unity 需要在后台解析依赖包、编译初始脚本和导入场景资源，这个过程可能需要 3 到 10 分钟。此时进度条卡在右下角是完全正常的，你可以起去倒杯水，耐心等待主界面加载出来。

成功进入 Unity 编辑器后，请确认以下四件事：

1. 确认顶部菜单栏中能看到 `VRChat SDK` 这一菜单。
2. 确认左下角的 Project（项目）面板的 Packages 目录下，正常显示了 SDK 相关的依赖包。
3. 确认底部的 Console（控制台）面板中，没有显示任何红色的错误图标（黄色的警告图标可以暂时忽略）。
4. 尝试按下 `Ctrl+S`，确认场景能够正常保存。

## Unity 编辑器：初次见面

第一次面对 Unity 的界面，你可能会觉得满屏的按钮和面板密密麻麻，有些让人望而生畏。但请先放下焦虑，在第一天，你只需要认识最核心的四块区域即可：

* **Scene 视图**（屏幕中央最大的区域）：这就是你搭建世界的画布。你可以用三维视角在里面摆放物品、调整灯光。
* **Hierarchy 面板**（通常在左侧）：场景中所有物体的目录清单。
* **Inspector 面板**（通常在右侧）：选中某个物体后，这里会展示它身上挂载的详细参数。
* **Project 面板**（通常在下方）：你整个项目的文件夹，存放着你的材质、模型、脚本和声音等文件。

随着开发的深入，你还会用到 Console 面板（看报错）和 Game 视图（模拟玩家视角）。但第一天，守住这最基础的四大块区域就足够了。

## 保持项目环境的纯净

新手容易在第一天就塞满各种炫酷的资源：Shader 包、现成模型插件、后处理特效、社区脚本库。

**请在第一阶段坚决收住这个念头。**

在你的第一个世界成功跑通之前，请只保留 VCC、Unity Hub、官方指定的 Unity 版本、Worlds SDK 以及一个干干净净的世界项目。等我们的地基打稳了，再去逐步添加其他工具。

:::tip[为什么是这样？]
这是软件开发中很重要的思维方式：「隔离变量」。一次只加一个新东西，出问题你立刻知道是谁引起的；一次塞十个插件，报错时排查就是灾难。
:::

:::caution[常见启动卡点排查]
* **VCC 提示找不到 Unity**：请打开 Unity Hub 确认对应的 Unity 版本是否已经成功安装，然后回到 VCC 的设置面板（Settings）中，手动指定正确的 Unity 编辑器路径。
* **首次加载卡在右下角**：这是 Unity 在生成初始缓存，耐心等待即可。如果超过十分钟依然毫无动静，可以强制关闭 Unity 并重新从 VCC 中点击启动。
* **Console 窗口弹出红色红字**：请优先检查你的 Unity 版本与 VRChat 官方指定的版本是否完全一致。很多奇怪的脚本报错，都是因为 Unity 的微小版本号对不上导致的。
:::

:::note[AI 小助手]
如果你遇到了任何无法理解的报错，可以点击 Console 窗口，选中该行报错，按下 `Ctrl+C` 复制其完整上下文，然后连同你的 Unity 版本号和 SDK 版本号一起发给 AI，让它帮你翻译并诊断。你可以对它说：「请帮我分析这个报错是环境配置错误，还是项目设置问题，并给出排查建议。」
:::
