在[物体与层级](/workbench/gameobjects/)中，禁用 Mesh Renderer 后地板不再显示，但 Collider 仍能阻挡玩家。组件可以分别控制外观、物理、声音或行为。

## 查看 Cube 的组件

创建一个 Cube，选中后在 Inspector 中检查：

1. **Transform**：位置、旋转、缩放。
2. **Mesh Filter**：引用网格资源。
3. **Mesh Renderer**：引用材质并绘制网格。
4. **Box Collider**：定义盒形碰撞区域。

组件之间可以独立配置，也可能存在依赖。例如，Mesh Renderer 需要可用的网格和材质，拾取物体需要同时满足 SDK 对碰撞与物理组件的要求。

## 添加组件

Inspector 底部点 `Add Component`，输入组件名并选择结果。添加以后仍需填写字段；组件存在不等于效果已经配置完成。

| 组件 | 作用 | 配置示例 |
| :--- | :--- | :--- |
| Light | 提供光源 | 类型、颜色、强度、范围 |
| Audio Source | 播放音频 | Audio Clip、音量、循环、空间化 |
| Collider | 定义碰撞或触发形状 | 形状、尺寸、Is Trigger |
| Rigidbody | 参与刚体物理 | 重力、质量、是否 Kinematic |
| Animator | 按控制器播放动画 | Controller、参数 |
| Udon Behaviour | 承载 Udon 程序 | 程序资产、字段引用 |
| VRC Pickup | 配置拾取行为 | 拾取方式及抓握设置 |
| VRC Object Sync | 同步物体的 Transform 和相关物理状态 | 所有权及同步配置 |

添加 Rigidbody 后是否下落，还取决于 `Use Gravity`、`Is Kinematic`、约束和碰撞条件。添加 Light 不会把网格材质自动改成自发光。

## 在 Inspector 调整字段

Light 的字段包括：

- `Type`：Point、Spot、Directional 等光源类型。
- `Color`：光色。
- `Intensity`：光照强度。
- `Range`：Point、Spot 的影响范围；Directional 不使用局部范围。

Audio Source 的字段包括：

- `Audio Clip`：要播放的音频资源。
- `Play On Awake`：音源启动时是否自动播放。
- `Loop`：音频结束后是否重复。
- `Spatial Blend`：`0` 为 2D，`1` 为完整 3D 混合。

2D 音源不根据听者与声源的距离、方向计算空间衰减，但仍受音量和混音设置影响。3D 音源的实际方向与衰减还受空间化器、距离参数等影响。空间化并不决定「进入某区域才播放」，那是另一项播放控制需求。

## 引用槽连接具体对象

Inspector 中显示 `None (Light)` 等文字的字段用于保存对象引用。例如，控制灯光的脚本声明了 `Target Light`，就需要指定要控制的那一个 Light 组件。

1. 在 Hierarchy 找到具有 Light 组件的物体。
2. 拖到 `Target Light` 槽中。
3. 检查槽里显示的是预期对象，而不是另一个同名物体。

如果字段仍为 `None`，脚本就没有这个目标引用。发生交互但灯不变化时，应同时检查事件是否执行、引用是否有效，以及灯是否处于能影响场景的设置下。

引用不会替作者决定目标。场景里有多盏灯时，给每个开关指定对应引用，才能明确它控制哪一盏。

## 禁用与移除组件

支持启用开关的组件可以临时取消勾选，观察其影响。需要移除时，使用组件菜单的 `Remove Component`。部分组件没有独立启用开关，不能一概用取消勾选代替移除。

- 禁用或移除 Collider 会改变碰撞；依赖该碰撞区域的交互也可能不再触发。
- 禁用 Renderer 会停止显示，但不自动关闭 Collider。
- 移除 Rigidbody 会改变依赖该刚体的物理行为。

若其他脚本保存了该组件的引用，移除组件后应检查引用是否失效。移除前可以保存场景或保留可恢复版本。

## Play Mode 修改的保存条件

按 Unity 顶部的 Play 按钮，会进入编辑器运行模式。此时修改场景对象，可以观察运行中的效果；退出时，场景对象的运行时修改通常会恢复。

需要保留某组运行时数值时：

1. 记录字段名和数值，或使用组件菜单复制组件值。
2. 退出 Play Mode。
3. 在编辑模式中重新填写或粘贴需要的字段。
4. 保存场景或 Prefab。

项目资源文件的直接修改不一定随退出 Play Mode 撤销，不能把「所有改动都会还原」当作保护机制。可以在 `Edit → Preferences → Colors` 调整 `Playmode tint`，帮助区分当前模式。

## VRChat 组件的职责

- `VRC Pickup`：配置可拾取物体。
- `VRC Object Sync`：同步其支持的物体状态，不会自动同步所有自定义脚本字段。
- `VRC Spatial Audio Source`：配置 VRChat 的音频空间化参数，配合 Audio Source 使用。
- `VRC Mirror Reflection`：配置镜面反射。
- `VRC Station`：定义玩家使用站点时的位置和行为，可用于座位。

这些组件有各自的实现和使用条件，不能统一称为 Udon 脚本。选用哪些组件取决于当前功能需求。
