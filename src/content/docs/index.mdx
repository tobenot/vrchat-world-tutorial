## 写作原则

1. 先做出来，再解释为什么。
2. 少甩术语，多给画面和手感。
3. 每章尽量留下一个能运行、能看见、能改着玩的成果。
4. 涉及 VRChat SDK、Unity、UdonSharp 的具体行为时，以官方文档和实际测试为准。
