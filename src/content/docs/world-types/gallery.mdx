Gallery 是展示绘画、摄影、模型、视频或空间装置的世界。作品可以静态展示，也可以包含旋转、解说、分层查看等交互。是否加入交互取决于展品需求，不据此区分展厅的质量或观众类型。

## 从展品清单确定布局

每件展品记录标题、作者、形式、尺寸、授权、观看方式和需要的说明。平面作品需要正面与近距离观察位置；雕塑需要检查绕行空间；视频作品需要屏幕、音频和播放控制。

观看顺序有两种基本组织方式：

- 按时间线或主题安排固定顺序，用编号、路标和通路说明方向。
- 自由浏览，用展区名称和导览图说明位置，不把所有内容绑定在单一路径上。

入口保留足够空间供多人出现和查看导览，避免出生点与展品的近看位置重叠。相邻展品的距离按尺寸和观看距离调整，不以固定米数作为所有展厅的标准。

### 可选方案：快看、慢看与接待

画两条参观路径：一条只读标题和概述，一条停下来读说明、绕行模型或播放解说。让两个人分别沿两条路线同时走，记录是否互相挡住近看位置、是否能跳过详细内容、是否能重新汇合。测试不规定固定停留秒数。

可在作品组之间留一段空白墙、过渡走廊或休息位，检查它是否使下一组的入口可辨认。地面纹理、通路宽度和围合可以提示行走方向；灯光、开口和可见的下一件作品可以提示观看方向。分别遮住路标再试一次，观察空间线索是否足够，必要的导览仍保留。

作者在场接待时，可在门厅侧边放介绍台、签名台或座位，确保等候者不挡住作品与通路；无人接待的展览不必添加这组设施。入口流程可写成“落地 → 看导览 → 选展线 → 走近作品”，逐步检查每个动作对应的位置。

| 可选展览安排 | 平面图上应明确什么 |
| :--- | :--- |
| 个人作品时间线 | 按日期或阶段排序，说明一组作品之间的变化，不靠作者在场补完顺序 |
| 多作者展 | 用分区与作者名区分作品，共用标题、作者、年份和许可的牌式 |
| 平面作品组 | 先试一致的画框与标牌位置，再检查它是否适合不同画幅 |
| 模型与空间装置 | 留模型绕行或旋转观察范围；独立房间之间有可辨认的出口和过渡 |
| 持续更新的展览 | 图上区分本次展位与预留展位，模拟增加一件作品后重新走展线 |

观众经世界搜索到访时，入口说明要能独立介绍展览；有导览活动时，还需标集合点。一次性展览不必为了假定的扩展保留空房间。

## 背景、灯光与作品颜色

背景墙、地面和灯光会改变作品的视觉对比。中性色、低反光的背景可减少对平面作品颜色的干扰；主题化建筑或装置展则可能需要空间本身参与展示。

可以把照明拆成三个用途分别调整：

1. 环境与通路照明：让入口、台阶和边界可见。
2. 作品照明：使作品的明暗、表面和轮廓符合展示意图。
3. 说明牌照明：保证文字在实际观看距离可读。

不需要每件展品都配置一组实时灯。对不移动的对象，可按条件使用烘焙灯和 Lightmap；动态雕塑或玩家头像还需检查 Light Probe 等光照来源。若要保留平面图像的原始颜色，可测试不受灯光影响的材质，并确认它与周围亮度不会形成过强反差。

### 可选练习：作品与背景对照

在场景副本固定一件作品和一个观察点，依次比较以下方案，每次只改一组设置：

1. 展品旁的装饰发光球开启或关闭，记录它是否遮挡细节或改变第一眼看向的位置；水彩作品旁的霓虹也可作同样对照，结果由展示意图决定。
2. 给同一展墙复制两份材质候选，分别试冷深灰与暖米白；保持作品贴图不变，降低 Smoothness，并单独比较有无 Normal 纹理，观察反光与墙纹是否干扰作品。
3. 按实际使用的光照方案分层测试：在 Lighting 的 Environment 设置环境照明；用基础灯照通路；再给需要的作品加定向的局部灯。对雕塑可另试主光、较弱补光与背光，检查正面细节和轮廓是否可辨。选择烘焙灯时按[烘焙操作](/placeness/light/)重新生成光照后比较。

记录灯类型、材质、平台和观察位置，不使用统一的强度倍数。若使用不受灯光影响的图像材质，灯光实验主要检查周边空间，不把它与受光材质的结果混在一起。

### 静态标记的范围

Unity 的 Static 是一组用途不同的标记，不等于“勾选后没有运行时开销”。烘焙时要核对对象是否参与全局光照、Renderer 的 Receive GI、Lightmap UV 和贴图密度。会移动或旋转的作品，不应为了得到烘焙阴影而无条件勾选全部 Static 标记。

烘焙后分别检查画框接缝、雕塑接地阴影和展柜反射。Reflection Probe 提供环境反射，并不自动等同实时镜面或玻璃的完整效果。

## 说明牌与导览

说明牌可使用 World Space Canvas 或 TextMesh Pro。文字是否清晰取决于字体资源、字形分辨率、物理大小、对比和观看距离，不能仅靠 Canvas 类型保证“分辨率自适应”。

在实际头显与桌面客户端检查：

- 从预定位置是否读得出标题和正文。
- 多语言文字是否有对应字形，不显示缺字方框。
- 标牌是否遮住作品或与墙面发生深度闪烁。
- 同时查看作品和标牌时是否需要频繁转身。
- 许可要求的作者、来源、许可证和修改说明是否可访问。

长说明可以分成概述和详细内容。解说音频提供字幕、播放与停止控制，不把听清音频设为理解展品的唯一方式。

可选的统一标牌样本是：第一行标题，第二行作者与年份，下方两句概述，另设详细说明入口。先在作品右下侧试放，再在下方试放；用高低视角各读一次，选择不遮作品、不挡近看位置的方案。具体字号与距离对照见[阅读距离与字号](/placeness/ui-and-feedback/)。

## 可选交互的状态范围

放大图片、切换语言和播放个人解说可以只影响本地玩家。需要集体导览时，再明确哪些页面、模型姿态或播放状态要共享。

区域解说可以由 Trigger 控制开始与停止；采用 2D 或 3D 是另一项决定。多个展品的解说范围相邻时，测试是否同时播放，并提供结束当前解说的方式。

模型旋转或 Pickup 展示需要检查碰撞与复位，避免展品被丢到无法观察的位置。没有这些需求时，静态展台已能完成展示。

为每项交互写一句“它帮助观察什么”：旋转用于看模型背面，放大用于看笔触，分层用于看构造。可选的纪念卡可以做成世界内可拿起、可复位的展览信息卡，但不能称为可跨世界带走的物品。若加入轻环境音，把它与作品解说分成独立控制，测试关闭环境音后仍能完成参观。

## 资源与性能

大型图片和模型会增加下载、显存和渲染开销。按实际观看距离选择贴图尺寸、压缩格式和模型细节，避免用同一设置处理所有作品。

分区可以减少同一视角中的可见内容，但不保证自动减少所有开销。需要结合遮挡、加载方式和实际测量判断。PC 与 Android 版本分别验证颜色、清晰度、视频播放和内存占用。

## 展厅验收记录

1. 标出展品位置、观看位置、灯光方向和通行路线。
2. 分别从入口、近看位置和展区之间的转折处检查可读性。
3. 两人同时看相邻作品，检查通路与解说是否相互干扰。
4. 对更换作品的操作跑一次完整流程：替换资源、更新署名、检查导入设置、测试并记录版本。

在同一张图上另标接待位、过渡段和预留展位。发布时对照实际入口制作缩略图与简介，写明展品形式、是否有音频解说、导览活动时间以及更新范围；不要让宣传图显示尚未布置的作品或功能。
