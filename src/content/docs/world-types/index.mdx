世界可以用于休息、游戏、社群活动、作品展示、叙事、演出、工具或商业服务。这些分类描述用途，不是质量或创作者能力的等级。

同一世界可以有多种用途。设计时分别列出空间、操作、共享状态、平台和人数需求，再检查功能之间是否冲突。

可选组合有：休息厅附一个小游戏，展厅附作者接待区，游戏结算后附一段故事。先写主要使用流程，再列附加功能；逐项检查它是否改变通路、音频、控制权或测试条件。例如展厅增加接待活动后，需要检查集合点与慢看作品的人是否互相挡路，不能只增加一个舞台模型。

按用途选择下列入口，再把所需操作列成一张清单。各类型章的“按用途查阅”把设计任务对应到实际配置与测试资料，可直接用于选读。
